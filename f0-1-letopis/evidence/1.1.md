# 1.1 — Ловушка Немила

## Файл НЕ отслеживается — игнор работает
```
$ git status --porcelain
$ git check-ignore -v .env
.gitignore:1:.env	.env
```

## Файл УЖЕ отслеживается — игнор бессилен
```
$ git check-ignore -v gramota.txt
$ git status --porcelain
 M .gitignore
 M gramota.txt
```

## Правило
Игнор действует только на неотслеживаемое. Отслеживаемому нужен git rm --cached.
