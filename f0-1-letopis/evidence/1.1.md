# 1.1 — Ловушка Немила

## Файл НЕ отслеживается — игнор работает
```
$ git check-ignore -v .env
.gitignore:1:.env	.env
$ git status --porcelain
 M .gitignore
 M gramota.txt
```

## Файл УЖЕ отслеживается — правило есть, а игнора нет
```
$ git check-ignore -v gramota.txt            # молчит: путь в индексе
$ git check-ignore -v --no-index gramota.txt # а правило на месте
.gitignore:2:gramota.txt	gramota.txt
$ git status --porcelain                     # и правки ловятся
 M .gitignore
 M gramota.txt
```

## Правило
Игнор действует только на неотслеживаемое. Правило может совпадать с путём и всё равно ничего не значить, пока файл в индексе. Вывести его оттуда — git rm --cached.
