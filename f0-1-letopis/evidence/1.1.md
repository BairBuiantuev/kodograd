# 1.1 — Ловушка Немила

## Файл НЕ отслеживается — игнор работает
```
$ git status --porcelain
 M .gitignore
 M gramota.txt
$ git check-ignore -v .env
.gitignore:1:.env	.env
```

## Файл УЖЕ отслеживается — игнор бессилен
```
$ git check-ignore -v gramota.txt
$ git status --porcelain
 M .gitignore
 M gramota.txt
```
