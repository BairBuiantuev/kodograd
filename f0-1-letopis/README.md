## Объектная модель руками

| герой | команда | что получилось |
|---|---|---|
| Мерило | `git hash-object -w gramota.txt` | blob `8c047a1f3637…` — то же клеймо дал и `hash-object --stdin` |
| Разложник | `git write-tree` | tree `9e46a8e6850d…`, внутри строки «режим · тип · хеш · имя» |
| Скрепник | `git commit-tree` | скрепа `516f4240454d…`, вторая `2fc9eea4dbb5…` с `parent 516f424` |
| Кивун | `git update-ref refs/heads/main` | ярлык `main` переехал на `2fc9eea` |

Что здесь важно заметить: blob не знает имени файла — имя появляется только в дереве.

## Каскад хешей

Одно и то же дерево с разной запиской дало разные скрепы:


Старую историю невозможно переписать, поскольку git хранит всё.

## Утечка: секрет пережил удаление

Секрет попал в историю скрепой `6e3f78d`, был «убран» скрепой `8d185fc` — и остался. Blob `86b3fb4c0329…` достаётся тремя путями: поиском по содержимому (`git log -p -S`), перечислением объектов (`git rev-list --objects --all`) и прямым чтением (`git cat-file -p`). Улика — `evidence/1.0.md`.

Правило Немила (улика `evidence/1.1.md`): `.gitignore` действует только на неотслеживаемое. Файл, попавший в индекс раньше правила, продолжает коммититься; вывести его оттуда можно только `git rm --cached`.

## Три шага починки — и третий главный

1. `git filter-repo` — вынуть секрет изо всей цепи.
2. Вымести подклеть: `git reflog expire --expire-unreachable=now --all && git gc --prune=now`, оповестить владельцев копий.
3. **Сменить сам секрет.**

## Мостик к Наслою

удаление в позднем слое образа не убирает файл из ранних слоёв; удаление в поздней скрепе не убирает blob из ранних. В обоих случаях старое лежит ниже и достаётся чтением, без запуска. Отсюда одинаковое следствие: секрет, попавший в слой или в скрепу, считается утёкшим, и лечится он не удалением, а ротацией.

## Печать Смоли

Отпечаток говорит ЧТО, печать — КТО. Поля author и committer — свободный текст и подделываются одной командой; целостность содержимого хеш гарантирует, авторство — нет. Ручательство даёт подпись: `gpg.format=ssh`, `commit.gpgsign=true`, проверка через `%G?` и список доверенных подписантов.
